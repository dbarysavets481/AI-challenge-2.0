# Leaderboard (AI Challenge - Task 1)

## Description

This project is a frontend implementation of a Leaderboard page based on provided reference screenshots.

The goal was to recreate the original UI and functionality as closely as possible, including layout, filtering, sorting, and interactive elements, while using only fictional data.

## Features

- Leaderboard with ranked employees
- Top-3 podium section
- Filtering by:
  - Year
  - Quarter
  - Category
- Search by employee name
- Combined filtering logic
- Sorting by score (descending)
- Dynamic rank recalculation after filtering
- Expandable employee rows
- Detailed "Recent Activity" table:
  - Activity
  - Category
  - Date
  - Points
- Empty state when no results are found
- Responsive layout (desktop + mobile)

---

## UI Details

- Clean corporate dashboard style
- Interactive hover states (icons, buttons)
- Expand/collapse animations
- Search input interaction (icon disappears on focus)
- Visual highlight for expanded rows
- Custom SVG icons

---

## Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)

No frameworks or backend were used.

---

## Data

All data used in this project is fictional:
- Employee names
- Roles
- Teams
- Activities

No real or original data from the reference was used.

## Notes

The implementation was created using a prompt-based approach with AI assistance (GitHub Copilot), followed by manual adjustments and refinement to match the reference design and behavior.
